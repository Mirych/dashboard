# Dashboard

Тестовое задание на Angular 22 + Taiga UI

Реализовано:
- авторизация и защищённые маршруты
- каталог товаров с добавлением, редактированием и удалением
- история покупок
- сохранение данных в LocalStorage

Дополнительно:
- поиск и фильтрация товаров
- статистика по каталогу
- Angular Signals и OnPush
- обработка ошибок и уведомления

## Запуск

```bash
npm install
npm start
```

Данные для входа: `test / Test1234`
